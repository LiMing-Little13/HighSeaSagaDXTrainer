# High Sea Saga DX 修改器

基于 Frida + IL2CPP 运行时挂钩的《High Sea Saga DX》（开罗海洋探险 DX）修改工具，使用 tkinter 图形界面读取与修改运行中的游戏数据。

## 功能

- **概览**：读取与修改金钱、食物/资源、奖牌、当前体力；每项支持锁定，按目标值周期性写回；锁定期间资源可直接编辑，编辑值自动成为新目标，轮询不会回填输入框、不会覆盖正在输入的内容；应用时超出输入上限或非法的项自动跳过（保留游戏当前值），其余项照常写入，跳过原因只显示在状态栏。
- **物品修改**：武器、道具、强化食物独立分页；支持多选批量修改数量，以及按列表显示的上限留出余量。
- **双六屋**：修改投掷次数、骰子数量、步数、目标格、开罗点数与卡片数量；支持次数锁定与步数锁定。
- **船员属性**：编辑基础数值、属性与额外成长；可单独恢复战斗 HP/SP。
- **修改器设置**：设置备份位置、锁定轮询间隔和启动时自动连接。

界面中的范围限制是输入约束，不是所有游戏场景下的安全保证。高属性与大量物品仍可能影响游戏计算或流程，修改前请保留备份。

游戏在存档时校验全部资源数值：金钱曾写满 20 亿后会被游戏内收入结算推过上限，导致游戏拒绝保存整个存档（与本次修改哪个字段无关）。因此金钱的输入上限设为 19 亿；读取时若发现资源为负或超过 20 亿，概览页会显示红色警告，按提示把超限值改回范围内即可恢复存档。应用资源修改时，输入超出上限或非法的项只跳过该项、保留游戏当前值，不会阻塞其它资源的写入，也不会弹窗。需要持续满额时建议改用“锁定”，让修改器周期性写回。

## 环境与启动

- Windows，Python 3.10+，tkinter。
- 直接运行 `python trainer.py` 使用当前命令行的 Python 环境，需自行安装 `frida==17.26.3`。
- `启动修改器.bat` 首次准备环境时要求 `%LOCALAPPDATA%\Programs\Python\Python312\python.exe` 处已安装 Python 3.12，且 `uv` 可从命令行调用；脚本使用 `uv venv` 创建本地 `.venv`，再用 `uv pip` 安装 `frida==17.26.3`。准备完成后使用 `.venv\Scripts\pythonw.exe` 启动修改器。
- Steam 版《High Sea Saga DX》，运行进程为 `KairoGames.exe`。
- 修改器从 Steam 注册表与 `steamapps\libraryfolders.vdf` 自动定位游戏安装目录，并备份其下的 `saves`。非标准安装可用环境变量覆盖：`HSSDX_GAME_ROOT` 指向安装目录，`HSSDX_GAME_SAVES` 直接指向存档目录。例如 PowerShell：

  ```powershell
  $env:HSSDX_GAME_ROOT = 'D:\Games\High Sea Saga DX'
  python trainer.py
  ```

先启动游戏并载入目标存档，再执行：

```bash
python trainer.py
```

也可双击 `启动修改器.bat`。

启动时默认尝试连接游戏。未连接成功时，进入游戏后点击“重新连接”，再点击“刷新数值”。在相应页面编辑后使用该页面的应用按钮；修改作用于游戏内存，由游戏自己的保存流程写入存档。

## 修改器设置

在“修改器设置”分页中修改并保存：

| 设置 | 默认值 | 说明 |
|------|--------|------|
| 备份位置 | 修改器目录下的 `backups` | 支持自选目录；保存为解析后的绝对路径。拒绝游戏安装目录及其子目录，也会解析符号链接等路径别名。 |
| 锁定轮询间隔 | 700 毫秒 | 可设置为 200～10000 毫秒的整数，用于剩余投掷次数与基础资源锁定的界面轮询；步数锁定由游戏运行时挂钩处理。 |
| 启动时自动连接 | 开启 | 关闭后可在启动后手动连接。 |

配置保存在修改器目录的 `trainer_settings.json`。目录不可用或保存失败时需根据界面错误调整路径或权限；路径校验不保证目标磁盘始终可写。

### 自动记忆窗口与列宽

- 拖动窗口调整大小或位置后自动记忆；下次启动恢复大小、位置与最大化状态。
- 恢复时会调整完全落在屏幕之外的位置。设置分页不提供宽度、高度等尺寸输入项。
- 页面布局随窗口伸缩，列表可随可用空间扩展。
- 武器、道具、强化食物分别记忆列宽，卡片列表单独记忆。

旧配置中的共享 `item_columns` 会在读取时迁移为三个物品分页各自的初始列宽，已有独立分页设置优先。读取配置不会主动改写文件；缺失、损坏或无效设置使用默认值，无关的未知配置键保留。后续保存采用同目录临时文件原子替换，并保留已有文件的 BOM、换行风格及末尾换行状态。

## 后台操作与刷新范围

游戏连接、读取与写入交由同一个串行后台工作线程执行，界面主线程接收结果和连接事件。后台操作期间不要把仍在执行的任务当作已完成。

- “刷新数值”用于完整读取，可能替换各页面当前显示或尚未提交的输入。
- 普通修改成功后只回读相关范围：资源、船员、对应物品分页或双六屋；不会为一次局部修改重新读取并填充全部页面。
- 锁定轮询只更新游戏内存和状态栏警告，不回填资源输入框；锁定期间可以持续编辑，只有“刷新数值”或成功应用对应字段才会改写输入框。后台轮询也不占用前台操作，轮询进行时仍可点击应用，操作会排队执行。
- 船员的战斗 HP/SP 恢复是独立操作，不会附带应用其他船员输入或写入资源。
- 写入成功但回读失败与写入失败分开提示。遇到前者不要直接重复应用，先刷新相关数据或重新连接确认实际结果。
- 断开连接与 Frida 错误通过事件队列交给界面处理，不从 Frida 回调线程操作窗口。

## 备份与目录保护

备份按**连接会话**管理：每个新连接会话首次需要写入前，先备份该会话的存档；同一会话后续写入复用该备份状态。重新连接后会重新执行首次写入前备份。

切换备份位置时，若当前连接已完成首次备份，会先在新目录重新备份，成功后才切换；若备份失败，则保留旧目录及已有备份保护。若当前连接尚未建立备份，则在下次写入前备份到新目录。

备份结构为：

```text
<备份位置>/YYYYMMDD-HHMMSS-微秒/saves/
```

请确认备份位置有足够空间与写入权限。备份失败时应先处理错误，再执行修改。备份是磁盘存档副本，不是当前内存状态快照，尚未由游戏保存的修改不会因此自动落盘。

**禁止向游戏安装目录写入文件或文件夹。** 修改器会自动识别 Steam 库中的安装目录，拒绝把备份位置设为该目录及其子目录；也可用 `HSSDX_GAME_ROOT` 显式指定安装目录。无法识别安装目录时不会阻止保存，需自行确认设置文件、备份和临时文件位于游戏目录之外。程序不提供自动恢复存档功能；请保留备份原件，恢复前先退出游戏并自行核对操作范围。

## 模块结构

```text
HighSeaSagaDXTrainer/
├── trainer.py              # tkinter 界面、串行后台任务与范围刷新
├── game_backend.py         # Frida 脚本、游戏读写、连接事件与会话备份
├── game_paths.py           # 定位游戏安装目录与存档目录
├── app_settings.py         # 设置默认值、校验、兼容迁移与原子保存
├── trainer_settings.json   # 本地配置：备份位置、锁定、连接、窗口与列宽
├── 启动修改器.bat          # Windows 启动入口
└── backups/                # 默认备份位置，首次备份时创建
```

`app_settings.py` 与 `game_paths.py` 仅依赖 Python 标准库，不导入 Frida 或游戏后端。公共接口为：

- `DEFAULT_BACKUP_ROOT`、`DEFAULT_SETTINGS_FILE`：默认路径，类型为 `Path`。
- `DEFAULT_LOCK_INTERVAL_MS = 700`。
- `validate_backup_root(value)`：返回校验后的绝对 `Path`；无效路径或受保护目录抛出异常，不创建目录。
- `SettingsStore(path=DEFAULT_SETTINGS_FILE).load()`：返回包含默认值及兼容迁移结果的字典。
- `SettingsStore(...).save(data)`：校验并原子保存；错误交由调用方处理。
- `detect_game_root()`、`game_saves()`：返回自动识别的安装目录与存档目录，无法识别时返回 `None`；均可用环境变量覆盖。

配置键为 `backup_root`、`lock_interval_ms`、`auto_connect`、可选的 `window_geometry` / `window_maximized`、`item_columns_by_tab`（`"0"`、`"1"`、`"2"`）与 `card_columns`。

## 常见问题

| 现象 | 处理方式 |
|------|----------|
| 未找到 `KairoGames.exe` | 启动游戏并载入存档，再重新连接。 |
| 游戏尚未初始化或未载入存档 | 进入游戏主界面并选中存档，再刷新。 |
| 数值修改后又变化 | 检查游戏自身的结算、锁定状态及写入/回读提示，先刷新确认，避免盲目重复写入。 |
| 游戏提示无法保存 | 概览页查看红色警告：某项资源（常见为金钱被收入结算推爆）为负或超过 20 亿时，游戏会拒绝存档；把该值改回上限以内即可，与其它字段的修改无关。 |
| 资源锁定被自动停止 | 连续 3 次读取或写入失败会停用资源锁定；进入游戏正常界面并刷新后重新勾选即可。 |
| 双六目标格未生效 | 先进入双六屋初始化棋盘，并确认目标格在当前位置之后。 |
| 备份位置被拒绝 | 选择游戏安装目录之外的目录，检查是否通过链接指向受保护位置，以及路径中是否含有同名文件。 |
| 备份提示未找到游戏安装目录或存档目录 | 非标准安装或非默认 Steam 库：设置 `HSSDX_GAME_ROOT` 或 `HSSDX_GAME_SAVES` 指向实际位置。 |
| 窗口设置未恢复 | 配置缺失或对应字段无效时使用默认值；检查配置位置与写入权限。 |
