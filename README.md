# High Sea Saga DX 修改器

基于 Frida + IL2CPP 运行时挂钩的 **《High Sea Saga DX》（开罗海洋探险 DX）** 存档修改工具，提供图形界面（tkinter），支持实时读取与修改游戏内存数据。

---

## ✨ 功能一览

### 🔗 游戏连接
- 自动检测并附着到 `KairoGames.exe` 进程
- 一键刷新读取当前存档所有数据

### 💰 基础资源修改（概览页）
| 资源 | 说明 |
|------|------|
| **金钱** | 金币数量（SecureLong 封装，自动加密校验） |
| **食物/资源** | 研究点数组第 0 项（亦作通用资源） |
| **奖牌** | 所有未过期奖牌计数之和，修改时自动调整首项 |
| **当前体力** | 体力数组第 2 项（仅修改当前值，不改上限） |

> 首次写入前自动备份存档到 `backups/` 目录（按时间戳命名）

### 🎒 物品修改（物品修改页 · 三大分页）
- **武器** / **道具** / **强化食物** —— 与游戏内背包分页完全一致
- 列表显示：名称、当前数量、持有上限
- 支持多选，批量设定目标数量
- **一键设为上限 - 9**：留出余量防止游戏内继续获得时溢出

### 🎲 双六屋（双六屋页）
#### 投掷标签
| 功能 | 说明 |
|------|------|
| **剩余投掷次数** | 可单次修改，或勾选“锁定”每 0.7 秒自动恢复至目标值 |
| **骰子数量** | 1~3 颗（影响总步数下限） |
| **总步数** | 1~99 步，可单次应用或勾选“锁定步数”每次投掷强制生效 |
| **目标格** | 设置目标格号，投掷前自动按 `目标格 - 当前位置` 计算步数，超过 99 步自动分多次投掷；到达/越过目标格或切关自动失效 |
| **开罗点数** | 0~2,147,483,647 |

#### 卡片标签
- 列出所有双六卡片：名称、当前数量、持有上限
- 多选批量修改数量
- **一键设为上限 - 1**：同上留余量

### 👥 船员属性（船员属性页）
- 下拉框切换当前编辑船员
- **基础数值**：等级、经验、当前战斗 HP、当前战斗 SP
- **六项基础属性**：HP、SP、攻击、防御、速度、智慧
- **六项额外成长**：同上六项的 `addParam_` 成长值
- **战斗 HP/SP 恢复满**：按游戏实时计算的上限（含职业、装备、技能、同伴/船只加成）填满
- **一键拉满上限**：基础设为 10,000，成长设为 9,980,000（HP/SP/攻/防/速合计 9,990,000，智慧同值）——此为探索/战斗安全上限，避免 32 位乘法溢出导致打不动怪、被秒杀或恢复异常
- 实时显示“剩余可分配额度”提示

---

## ⚠️ 重要限制与安全提示

1. **属性溢出保护**  
   - HP/SP/攻击/防御/速度：**基础 + 成长 合计 ≤ 9,990,000**  
     （战斗中会乘属性相性、技能百分比放大，均为 32 位乘法，超限会导致探索失败）  
   - 智慧：仅固定加法，**合计 ≤ 2,000,000,000**（32 位有符号整数上限，溢出归 1）

2. **首次写入自动备份**  
   存档会完整复制到 `backups/YYYYMMDD-HHMMSS-微秒/saves/`，可手动恢复。

3. **仅修改内存，不落盘**  
   修改直接作用于运行中进程；游戏自动存档或手动保存后才会写入硬盘。

4. **需先启动游戏并载入存档**  
   修改器通过 Frida 挂钩 IL2CPP 运行时，游戏未运行或未进主界面无法连接。

## 🛠 依赖环境

| 组件 | 版本要求 |
|------|----------|
| Python | 3.10+ |
| Frida | `pip install frida-tools`（需与本机 `frida-server` 架构一致） |
| tkinter | Python 标准库自带 |
| 游戏 | Steam 版《High Sea Saga DX》（IL2CPP / x64） |

> 首次运行需确保 Frida 环境正常：`frida --version` 无报错即可。

## 🚀 使用方法

1. 启动游戏，进入主界面并载入目标存档
2. 运行修改器：
   ```bash
   python trainer.py
   ```
   或双击 `启动修改器.bat`
3. 点击 **“重新连接”** → 显示 `已连接：KairoGames.exe (PID xxx)`
4. 点击 **“刷新数值”** 读取当前数据
5. 在各标签页修改所需数值，点击对应 **“应用”** 按钮
6. 游戏内即时生效；建议在游戏内手动存档一次落盘

## 📁 目录结构

```
HighSeaSagaDXTrainer/
├── trainer.py              # 主程序
├── trainer_settings.json   # 窗口位置/列宽等 UI 设置（自动生成）
├── 启动修改器.bat          # Windows 一键启动脚本
├── .gitignore              # 忽略缓存、备份、本地配置
├── backups/                # 自动备份的存档（按时间戳，不提交）
└── __pycache__/            # Python 字节码缓存（不提交）
```

## ❓ 常见问题

| 现象 | 原因与对策 |
|------|------------|
| 连接失败“未找到 KairoGames.exe” | 游戏未运行、或进程名不一致（Steam 版固定为 `KairoGames.exe`） |
| 刷新报错“游戏尚未初始化/尚未载入存档” | 请进入游戏主界面、选中存档后再点刷新 |
| 修改后数值没变 / 立刻复原 | 游戏有加密校验（SecureLong/ExInt），修改器已内置加密写入与回读校验；若仍失败请重启游戏重试 |
| 属性改高后探索/战斗异常 | 超过安全上限导致 32 位乘法溢出，请按提示降低数值 |
| 双六目标格不生效 | 需先进入双六屋触发棋盘初始化，且目标格必须大于当前位置 |
